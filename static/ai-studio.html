Твоя AI-студия

Единая панель для изображений, видео, сценариев и истории задач. Панель работает через существующий API проекта и не хранит API-ключ в браузере.

Генератор изображения

Создаёт изображение через настроенный серверный AI-провайдер.
Если добавить референс человека, система передаст исходное изображение генератору и включит строгую фиксацию лица и пропорций тела.

Быстрые пресеты

Нажми — текст попадёт в основной промпт.

Простое видео

Текст → видео. Для image-to-video можно добавить референс.

Креативный видеогенератор

Идея разбивается сервером на сцены и проходит через существующий конвейер создания видео.
Референс передаётся в конвейер сцен; при наличии человека сохраняются лицо и пропорции тела.
