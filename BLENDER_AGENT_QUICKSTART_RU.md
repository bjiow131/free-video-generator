# Быстрый запуск локального Blender Work Agent

## Назначение и границы

Это локальный помощник только для Blender. Он не подключается к ChatGPT, не получает удалённые задания, не опрашивает GitHub mailbox и не управляет браузером или другими приложениями.

**Текущая реализация ограничена одной демонстрационной задачей:** запустить настоящий Blender с графическим интерфейсом, создать сцену лесной тропы, сохранить файл .blend и отрендерить PNG. Blender запускается не в фоновом режиме, поэтому окно программы будет видно во время выполнения. Это пока не универсальный агент, который умеет выполнять любые текстовые инструкции; новые типы Blender-действий нужно добавлять отдельно и безопасно.

## Что должно быть установлено

- Windows 10/11.
- Python 3.11 и Python Launcher (py).
- Blender 5.2 по умолчанию: C:\Program Files\Blender Foundation\Blender 5.2\blender.exe.

Если Blender установлен в другом месте, измените BLENDER_EXECUTABLE в setup_blender_agent.bat и run_blender_agent.bat.

## Установка

1. Скачайте [ZIP ветки blender-agent-repair](https://github.com/bjiow131/free-video-generator/archive/refs/heads/blender-agent-repair.zip).
2. Распакуйте, например, в C:\AI-Agent\free-video-generator. В папке должны быть BAT-файлы, local_agent и requirements-local-agent.txt.
3. Запустите setup_blender_agent.bat. Он создаст отдельное Python-окружение в %LOCALAPPDATA%\BlenderWorkAgent\venv и установит ярлык автозапуска агента в папку автозагрузки текущего пользователя Windows. Зависимости через pip и GitHub-токен не нужны.
4. Запустите run_blender_agent.bat. Сначала выполнится локальная проверка Python, Blender и рабочей папки. Сцена не создаётся без отдельного подтверждения Y. После подтверждения откроется Blender с графическим интерфейсом и запустится создание сцены/рендер.
5. Если подтвердили создание сцены, введите имя проекта (по умолчанию mia_forest). Если эта папка уже содержит результаты предыдущего запуска, выберите новое уникальное имя.

## Результаты

По умолчанию файлы будут в C:\AI-Agent-Workspace\mia_forest\:

- forest_starter.blend — проект Blender;
- forest_preview.png — предварительный рендер;
- blender_result.json — сведения о результате;
- локальные логи Blender.

Имя папки проекта может содержать только латинские буквы, цифры, подчёркивания и дефисы. Для остановки долгой задачи используйте Ctrl+C в окне запуска.

## Как будем передавать задачи

Ты описываешь задачу в ChatGPT. Я готовлю конкретную команду для локального Blender-помощника; ты запускаешь её на компьютере и возвращаешь сюда результат. Агент не получает от меня команды напрямую.

Пока доступна только демонстрационная задача forest-preview. Не вставляй в агент произвольный Python-код и не считай, что он уже умеет автоматически создавать любые сцены. Следующий этап — расширять набор типизированных Blender-команд и проверять каждую локальными тестами.

## Автозапуск

После установки ярлык Blender Work Agent появляется в автозагрузке Windows. При входе в систему открывается консоль агента и запрашивает подтверждение перед созданием сцены. Для создания сцены Blender GUI открывается по подтверждению; сам Blender не запускает рендер автоматически без согласия. Чтобы отключить автозапуск, запусти `uninstall_blender_agent_autostart.bat`. Чтобы установить его повторно, используй `install_blender_agent_autostart.bat`.
