# Импорт паспорта персонажа в Blender Work Agent

## Где находится функция

Открой настольное приложение и перейди в **Библиотека** → **Импортировать паспорт…**. Выбери JSON-паспорт. Программа не исполняет содержимое файла как код.

Можно дополнительно прикрепить:
- модель Blender \`.blend\` (до 2 ГБ);
- изображения-референсы PNG/JPG/WebP/BMP/TIFF (до 30 МБ каждое).

## Что происходит автоматически

1. Проверяется JSON, версия схемы и безопасный ID персонажа.
2. Паспорт сохраняется как новая версия в \`BlenderAgentLibrary/<id>/passport_versions/\`.
3. При наличии модели она копируется в \`model/\`; изображения — в \`references/\`.
4. Карточка персонажа создаётся или обновляется в \`characters.json\`. Существующие описания и ссылки на референсы сохраняются.
5. В карточке обновляются версия паспорта, статус аудита и сводка рига. Библиотека обновляется в текущем окне без перезапуска.

## Формат

Поддерживаются:
- один JSON-объект с \`schema_version: 1\` и \`character_id\`;
- реестр \`character_passports.json\` со словарём \`characters\`, где для каждого персонажа есть массив \`history\`. Для реестра с несколькими персонажами приложение попросит ID.

В паспорте могут присутствовать поля \`status\`, \`source\`, \`rig\` и \`audit\`. Неизвестные поля исходного паспорта сохраняются в версии паспорта, но не исполняются.

## Где хранятся данные

По умолчанию: \`%USERPROFILE%\\BlenderAgentLibrary\\\`.

- \`characters.json\` — карточки, используемые интерфейсом и планировщиком сцен;
- \`<id>/passport_versions/vNNNN.json\` — неизменяемые версии импортированных паспортов;
- \`<id>/references/\` — скопированные референсы;
- \`<id>/model/\` — прикреплённая модель Blender.

Исходный JSON, изображения и \`.blend\` не редактируются. Повторный импорт того же ID создаёт новую версию паспорта и обновляет существующую карточку вместо дубликата.

## Важные ограничения

Импорт паспорта не означает, что модель уже корректно риггирована или готова к рендеру. Статус и список контроллеров берутся из паспорта и считаются предварительной диагностикой. Перед production-анимацией нужно открыть модель в Blender, проверить деформации и подтвердить работу контроллеров. Автоматический импорт не запускает пользовательский Python-код.
