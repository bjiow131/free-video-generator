## Изменения Studio

Раздел **Паспорта → Мия** содержит:
1. Предпросмотр утверждённого JPEG с серверной проверкой SHA-256 и размера, без сетевых запросов и API-ключей.
2. Статус синхронизации: «проверен», «нет файла» либо «не прошёл проверку». При ошибке не отображается неподтверждённый файл.
3. Кнопку «Закрепить этот эталон в паспорте»: только действие пользователя, локально копирует точные байты в `mia_story/studio_media` и устанавливает существующее поле `characters.mia.reference` в state JSON. Другие поля, сцену и реквизит не меняет. Revision CAS защищает от параллельных сохранений.
4. Этапы: визуальный эталон; точный кадр 2.5D; движение 5 с; 3D mesh; body/face rig; проверка ракурсов. Не готовые этапы обозначены как pending.
5. Общие миниатюры персонажа Мия показывают утверждённый эталон. Одобрение 3D не подразумевается.

## Инженерные правила

- Не создавать новую Мию процедурными примитивами и не объявлять тестовую геометрию канонической моделью.
- 2.5D: сначала показать неподвижный кадр в исходном ракурсе. Для реальной анимации понадобятся подготовленные слои, перекрытия и восстановление скрытых частей. Это ещё **не реализовано**.
- 3D: с нескольких согласованных ракурсов создать модель с объёмной геометрией, волосами и одеждой; затем риговать тело и лицо. Нельзя обещать стопроцентное совпадение неизвестных ракурсов по одному исходному JPEG.
- Приёмка каждого этапа требует сравнения с утверждённым визуальным эталоном; без него блокировать выпуск сцены.
- Ни OctavAPI, ни Blender в этой операции не вызываются. Нет новых AI-изображений, 3D-реконструкций или рендеров.
- Токены и приватные материалы не загружаются на внешние хосты. GET изображений доступен только локальной Studio на `127.0.0.1`.

## Установка

Это новая ветка исходного кода; она **не появится на пользовательском Windows сама по себе**. Текущий безопасный updater не позволяет удалённо менять весь Studio. Устанавливать только отдельно проверенным локальным пакетом с pinned SHA файлов, копированием и возможностью отката. После установки открыть Studio → Паспорта → Мия и проверить статус «Подтверждён контрольной суммой SHA-256», затем нажать «Закрепить этот эталон в паспорте». Если статус «Не найден», сначала синхронизировать утверждённый приватный файл через существующий безопасный `sync_approved_assets`.

## Зафиксированные критерии приёмки

- Все HTTP-ручки проверяют Host и для записи браузерный Origin.
- Никаких произвольных path/URL из параметров запроса.
- Неверный хеш, размер или симлинк блокируют изображение.
- Привязка не меняет остальные поля Мии и не добавляет дубликатов.
- Сохранение state продолжает работать с прежним schema_version=1.
- Windows/Linux тесты, JavaScript syntax, существующие Studio tests.
