# Official Blender documentation catalog

Prefer documentation matching the exact Blender version installed on the target PC. The `current` links below may describe a newer release than the local installation.

- Python API: https://docs.blender.org/api/current/
- Python API — Scene: https://docs.blender.org/api/current/bpy.types.Scene.html
- Manual — Modeling: https://docs.blender.org/manual/en/latest/modeling/index.html
- Manual — Modifiers: https://docs.blender.org/manual/en/latest/modeling/modifiers/index.html
- Manual — Materials and Principled BSDF: https://docs.blender.org/manual/en/latest/render/shader_nodes/shader/principled.html
- Manual — Armatures: https://docs.blender.org/manual/en/latest/animation/armatures/index.html
- Manual — Weight Paint: https://docs.blender.org/manual/en/latest/sculpt_paint/weight_paint/index.html
- Manual — Animation: https://docs.blender.org/manual/en/latest/animation/index.html
- Manual — Cameras: https://docs.blender.org/manual/en/latest/render/cameras.html
- Manual — Rendering: https://docs.blender.org/manual/en/latest/render/index.html
- Manual — Command-line arguments: https://docs.blender.org/manual/en/latest/advanced/command_line/arguments.html
- Manual — Troubleshooting: https://docs.blender.org/manual/en/latest/troubleshooting/index.html
- Manual — Saving files and assets: https://docs.blender.org/manual/en/latest/files/index.html

This repository stores original summaries and workflow guidance, not a wholesale copy of the official manual. When the agent encounters an API behavior it cannot establish, it should consult the relevant official versioned documentation or escalate.
