# Blender AI Agent — Studio UI: ограниченная локальная анимация

## Проверенные возможности

- Утверждённый тёмный Studio UI, паспорта персонажей, реквизит, сцены и настройки из v1.
- Локальное сохранение состояния с revision и атомарной заменой `studio_state.json`; прежний `story_plan.json` не перезаписывается.
- Новый интерпретатор русских команд: **явно названный тестовый персонаж** умеет идти (перемещение тестового тела), поворачивать, махать тестовой рукой, открывать/закрывать рот по временным окнам и стоять. Камера следует, удерживается или приближается. Это **не полноценная ходьба ригованного героя**.
- Новый рендер в Blender: создание геометрии исключительно для названного тестового персонажа, реальных ключевых кадров движения и камеры, PNG-кадров, `scene.blend`, тихого MP4 из кадров посредством локального FFmpeg.
- Очередь одной задачи, сохранённые JSON-статусы, фактический счётчик PNG-кадров, запрос статуса по ID, отмена, тайм-аут, перезапуск помечает незавершённое задание как interrupted.
- `/api/interpret`, `/api/render-scene`, `/api/studio-job/<id>`, `/api/studio-latest`, `/api/studio-video/<id>` — только loopback и same-origin.

## Ограничения

1. **Мия и остальные реальные персонажи пока не анимируются**. Нужны реальные Blender-риг/модель, соответствующие движения; 2D-референсы недостаточны. Соответствующие запросы блокируются с точной подсказкой `assets/<id>.blend` и необходимыми анимациями. Название `test actor` / «тестовый персонаж» означает демонстрационный объект, не Мию.
2. Пока нет исполнения езды, бега, подъёма предметов, сложных декораций и взаимодействий; проектный монтаж работает только для уже отрендеренных сцен.
3. Интерпретатор детерминированный: обрабатывает ограниченные известные глаголы и не гарантирует понимание произвольного художественного описания.
4. Реализована **сборка двух и более уже готовых тестовых сцен в единый MP4** через локальный FFmpeg (без аудиотрека). Порядок определяется текущей раскадровкой; все клипы должны иметь одинаковые FPS и разрешение. Python + FFmpeg-тест подтвердил корректный порядок красной и зелёной сцен.
5. Версия не проверена в реальном Blender 5.2.2 на Windows или Linux: в среде сборки Blender недоступен. Все подтверждённые тесты — Python и JS syntax; рендер требует проверки на установленной машине.

## Безопасная установка

Остановите Blender Studio и, если запущен, `run_github_mailbox_agent.bat`. Распакуйте архив в `C:\AI-Agent-Studio-Update` без вложенного лишнего уровня. После резервного копирования файлов обновления запустите:

```powershell
powershell -ExecutionPolicy Bypass -File "C:\AI-Agent-Studio-Update\install_blender_studio.ps1" -Target "C:\AI-Agent"
```

Установщик не меняет `C:\AI-Agent-Workspace`, `studio_state.json`, `story_plan.json`, референсы или сохранённые видео. Он не удаляет старые файлы проекта и перед заменой копирует изменяемый код в папку `C:\AI-Agent\backup-studio-YYYYMMDD-HHMMSS`. Имя папки выводится установщиком. Откат:

```powershell
powershell -ExecutionPolicy Bypass -File "C:\AI-Agent\rollback_blender_studio.ps1" -Target "C:\AI-Agent" -Backup "C:\AI-Agent\backup-studio-YYYYMMDD-HHMMSS"
```

## Запуск и проверка

```powershell
cd C:\AI-Agent
py -3.11 -m unittest discover -s tests -p test_prompt_pipeline.py -v
py -3.11 -m unittest discover -s tests -p test_studio_approval.py -v
py -3.11 -m unittest discover -s tests -p test_studio_assembly.py -v
.\run_blender_studio.bat
```

В Studio введите «Тестовый персонаж идёт, затем поворачивается и говорит. Камера следует», нажмите «Создать первую сцену», просмотрите действия в разделе «Рендер», затем «Сгенерировать сцену». В `C:\AI-Agent-Workspace\mia_story\studio_jobs\<job_id>` должны появиться `manifest.json`, `scene.blend`, каталог `frames`, `blender.log`, `ffmpeg.log` и `scene.mp4`. Файл должен содержать движущиеся кадры. Для реальных персонажей система пока должна отказывать с указанием недостающих файлов, а не запускать тестовую геометрию.
